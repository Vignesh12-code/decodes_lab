    "# DecodeLabs Project 3 - Unsupervised Learning\n",
    "\n",
    "## Customer Segmentation Using K-Means\n",
    "\n",
    "### Overview\n",
    "\n",
    "This project was completed as part of the DecodeLabs Data Science Internship - Project 3.\n",
    "\n",
    "The objective of this project is to perform customer segmentation using unsupervised machine learning techniques.\n",
    "\n",
    "The project uses customer purchasing behaviour to discover hidden groups of similar customers without predefined labels.\n",
    "\n",
    "---\n",
    "\n",
    "## Project Requirements\n",
    "\n",
    "The project focuses on:\n",
    "\n",
    "- Customer segmentation\n",
    "- Principal Component Analysis (PCA)\n",
    "- K-Means clustering\n",
    "- Elbow Method\n",
    "- Silhouette Score\n",
    "- Business persona interpretation\n",
    "\n",
    "---\n",
    "\n",
    "## Technologies Used\n",
    "\n",
    "- Python\n",
    "- Pandas\n",
    "- NumPy\n",
    "- Matplotlib\n",
    "- Seaborn\n",
    "- Scikit-Learn\n",
    "- Jupyter Notebook\n",
    "\n",
    "---\n",
    "\n",
    "## Methodology\n",
    "\n",
    "### 1. Data Loading\n",
    "\n",
    "The retail dataset is loaded using Pandas.\n",
    "\n",
    "### 2. Data Cleaning\n",
    "\n",
    "Duplicate records and missing values are handled before performing the clustering analysis.\n",
    "\n",
    "### 3. Customer-Level Aggregation\n",
    "\n",
    "Transaction-level data is converted into customer-level information using CustomerID.\n",
    "\n",
    "Customer behaviour features include:\n",
    "\n",
    "- Total Spending\n",
    "- Average Order Value\n",
    "- Total Quantity\n",
    "- Average Unit Price\n",
    "- Total Items in Cart\n",
    "- Number of Orders\n",
    "\n",
    "### 4. Feature Scaling\n",
    "\n",
    "StandardScaler is used to standardize the numerical features before applying distance-based clustering.\n",
    "\n",
    "### 5. Principal Component Analysis\n",
    "\n",
    "PCA is applied to reduce the feature space to two dimensions.\n",
    "\n",
    "This makes it easier to visualize the customer segments.\n",
    "\n",
    "### 6. Elbow Method\n",
    "\n",
    "The Elbow Method is used to evaluate different numbers of K-Means clusters using inertia.\n",
    "\n",
    "### 7. Silhouette Score\n",
    "\n",
    "Silhouette Scores are calculated for different values of K.\n",
    "\n",
    "The K value with the strongest silhouette performance is used to select the final number of clusters.\n",
    "\n",
    "### 8. K-Means Clustering\n",
    "\n",
    "K-Means is trained using the selected optimal number of clusters.\n",
    "\n",
    "Each customer is assigned to a cluster based on purchasing behaviour.\n",
    "\n",
    "### 9. Customer Personas\n",
    "\n",
    "The average characteristics of each cluster are analyzed.\n",
    "\n",
    "The clusters can then be translated into meaningful business personas such as:\n",
    "\n",
    "- High-value customers\n",
    "- Regular customers\n",
    "- Low-engagement customers\n",
    "- Occasional customers\n",
    "\n",
    "The exact persona interpretation depends on the actual cluster statistics produced by the model.\n",
    "\n",
    "---\n",
    "\n",
    "## Project Outputs\n",
    "\n",
    "The project produces:\n",
    "\n",
    "- PCA visualization\n",
    "- Elbow Method graph\n",
    "- Silhouette Score graph\n",
    "- K-Means customer segmentation visualization\n",
    "- Cluster statistics\n",
    "- Customer segmentation results CSV\n",
    "- Customer cluster summary CSV\n",
