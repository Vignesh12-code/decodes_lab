# Advanced EDA & Feature Engineering

## Project Overview

This project was completed as part of the **DecodeLabs Industrial Training Kit 2026**. The objective was to transform a raw e-commerce transaction dataset into a clean and machine-learning-ready dataset using statistical preprocessing techniques.

## Tasks Performed

* Missing value handling using **Mode Imputation**
* Outlier detection and treatment using the **IQR method**
* Feature engineering with **4 new predictive features**
* Exploratory Data Analysis (EDA)
* Correlation analysis using a **heatmap**
* Data visualization using **Matplotlib** and **Seaborn**
* Exported a cleaned dataset for future machine learning tasks

## Engineered Features

* `OrderMonth`
* `OrderYear`
* `AvgItemValue`
* `CartEfficiency`

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy
* Jupyter Notebook

## Dataset Information

The dataset contains **1200 e-commerce transaction records** with customer, product, payment, and pricing information.

## Output

The final cleaned dataset was saved as:

`cleaned_ecommerce_dataset.csv`

This dataset is now suitable for **advanced analytics, business intelligence, and predictive modeling applications**.
